# The American Surcharge: error reports

This is where to report an error on [americansurcharge.com](https://americansurcharge.com).

Every figure, quote, and claim on the site is tied to a source. If one is wrong, out of date, or says more than its source does, open an issue here.

## What to include

- The page address.
- The sentence or number in question.
- What is wrong, and a link to a source that shows it. Official statistics, statutes, and agency pages carry the most weight.

Each page on the site has a "Report an error" link that fills in the first two for you.

## What happens next

Confirmed errors are fixed on the site and listed in the corrections log on the [method page](https://americansurcharge.com/method).

This repository holds reports only. The site's code and content live elsewhere.
